# Hermes Agent

公式ドキュメント: https://hermes-agent.nousresearch.com/docs/

Hermes Agent は [Nous Research](https://nousresearch.com) が開発する自己改善型 AI agent です。CLI / TUI / Desktop から利用でき、memory、skills、tools、subagent、cron、Messaging Gateway、MCP などを組み合わせて継続的な作業を実行できます。

日本語版では、upstream の実装と英語ドキュメントを正本として、利用開始と日常運用に必要な内容を短く整理します。CLI 名、設定名、provider 名、path は翻訳せず、実装と同じ表記を使います。

## インストール

### Windows / macOS

Hermes Desktop:

https://hermes-agent.nousresearch.com/

### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

### Windows (PowerShell)

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

インストール後、provider / model を設定します。

```bash
hermes model
```

Nous Portal を使う場合は次が最短です。

```bash
hermes setup --portal
```

起動:

```bash
hermes
# または
hermes --tui
```

## 安定して使う順序

1. install が完了する
2. `hermes model` で model/provider を確定する
3. `hermes` で通常会話を成功させる
4. `hermes doctor` で重大な問題がないことを確認する
5. 必要な tools / memory / skills を有効にする
6. その後に gateway / cron / MCP / remote backend を追加する

基本会話が壊れた状態で機能を積み増さない方が、問題の原因を切り分けやすくなります。
